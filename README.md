# Uncle Tony AI 🤖

An AI-powered Telegram assistant built with Python and Hermes.

## Features

- Telegram chatbot
- AI responses using Hermes
- Secure environment variables (.env)
- GitHub version control
- Ready for cloud deployment

## Project Structure

```
telegram-agent/
│
├── bot.py
├── config.py
├── docs/
├── handlers/
├── core/
├── memory/
├── services/
├── tests/
├── utils/
├── .env
├── .gitignore
└── README.md
```

## Requirements

- Python 3.12+
- Hermes CLI
- Telegram Bot Token

## Run

```bash
source .venv/bin/activate
python bot.py
```
